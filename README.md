# Изгиб Питона - Игра Змейка

Классическая игра "Змейка", реализованная на Python с использованием Pygame и принципов ООП.

## Особенности

- Реализация на принципах объектно-ориентированного программирования
- Плавное управление
- Прохождение через стены
- Столкновение с собой заканчивает игру
- Случайное появление яблок
